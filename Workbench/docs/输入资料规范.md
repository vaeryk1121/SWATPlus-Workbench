# 输入资料规范与跨流域处理

本页汇总通用规范和当前已适配产品。与流域有关的实测值、分类表和管理参数由案例提供，不把南小河沟或Robit专用表当通用数据库。

## 必须准备或确认的信息

|资料|要求与用户判断|
|---|---|
|DEM|单波段，已知CRS，高程为米；确认目标米制投影、分辨率和处理域。程序不猜垂直基准、不自动补DEM洞。|
|出口/河网|出口坐标及CRS，或完整Shapefile；确认真实汇水出口、吸附距离、参考河网及引调水。自动出口表含ID/INLET/RES/PTSOURCE。|
|土地利用|有CRS的整数分类图、年代、来源代码→SWAT代码对应表。分类用最近邻；未知类别不靠猜测补齐。|
|土壤|土壤分类图及配套ID、剖面和分层属性；必须匹配同一数据产品，不能混接HWSD2图与另一库编号。|
|日气象|站号、经纬度、高程、日期、变量、单位、缺测码/质量码及研究时段；确认站点代表性。|
|WGN|完整可靠的站点/月参数库或配套两CSV；允许补缺时明确选择，生成量与实测区分。|
|构建设置|河网/HRU阈值、模拟起止和预热；可以另存新方案后重建，不建议覆盖已完成任务。|
|研究资料|率定/验证观测的来源、单位、时段及模型对象对应；水库/灌溉另需真实属性、规则、水源和操作资料。|

## 格式与单位

- 土地对应表：LANDUSE_ID/SWAT_CODE；土壤对应表：SOIL_ID和SNAM或NAME。仅兼容语义明确的旧别名，不改变类别含义。
- 土壤支持官方152列宽表，或11列主表＋17列分层表；层号从1连续，soil_id对应主表，层底深度mm递增。可按明确映射转换CSV/TSV/XLSX，XLSX须指定工作表和表头。
- 深度mm/cm/m；容重g/cm³或明确等价单位；AWC为体积分数mm/mm；导水率统一mm/h；粒径、碳及粗颗粒须明确百分比/小数和质量/体积基准。pH=0等未知值不得当测定值。
- 日气象：降水mm、最高/最低温度°C、太阳辐射MJ/m²/day、相对湿度0—1、风速m/s。日照时数须经方法推算辐射，不能直接改列名。
- SWAT+索引pcp.cli/tmp.cli/slr.cli/hmd.cli/wnd.cli与所引用日文件一起提供；tstep=0，年/积日连续且覆盖模拟期。新温度文件采用.tem，仍能读取旧.tmp。旧SWAT2012站点索引/日文件由Editor原生接口转换。
- WGN两CSV为站点和12个月表；数据库须明确站点表和同名_mon表。检查月份、单位、概率、湿日数、降水统计；非零未知占位值不能靠裁剪伪装有效。

## 当前已适配的通用产品

|路线|处理与限制|
|---|---|
|官方QSWAT+配套土壤|global_soils/global_usersoil与配套地图编号一起使用，导出主表/分层表。当前本地地图为粗分辨率欧亚瓦片，不能当作精细当地调查。|
|HWSD2|按图斑ID只读查询，同一完整组分取最大SHARE，并列按SEQUENCE；保留该组分七层。Saxton–Rawls矿质土PTF估算水力属性，EPIC/Williams估算可蚀性，NEH2009分水文组。|
|官方WGN|本地SQLite含177575站/2130900个月记录，按位置筛选所需站/月；是CFSR派生气候统计，不是当地实测日天气。|
|CMA V3全国月文件|读TEM/PRE/RHU/WIN/SSD，按站号或位置筛选，保留迁站/高程和质量信息；日照按FAO56显式系数估算辐射。|
|明确列映射的逐日表|确认列名/列号、日期、站点、单位及缺测/质量码，再生成日文件及索引。不同产品仍需专门适配。|

HWSD2估算不适用于所有泥炭/特殊土；城市7001等无物理属性单元继续报缺项。OC→OM用1/0.58为经验换算；粗颗粒质量/体积换算采用明确的2.65颗粒密度假设。根深、水位、限制层、裂隙和反照率等方案项必须确认，不伪装成数据库观测。不能把根区总AWC写成每层AWC。

本地通用资料：`data/raw/shared/wgn/swatplus_wgn.sqlite`、`official_soil/ea_soil.vrt`、`official_landuse/ea_landuse.vrt`（后两者均在data/raw/shared）。官方属性库在`<SWATPlus支持目录>/Databases/QSWATPlusProj.sqlite`。HWSD2原库在`<HWSD2目录>/HWSD2_DB/HWSD2.mdb`；栅格使用完整HWSD2_RASTER子目录，不能使用上层16KB同名坏文件。

## CMA V3解码要点

以已核对的SURF_CLI_CHN_MUL_DAY_V3.0格式说明为准。海拔0.1m且+100000标估测；温度0.1°C、风速0.1m/s、湿度1%、日照0.1h。质量0正确、1可疑、2错误、8缺测、9未控；已验证方案只接受0。

32766缺测；32700微量雨按显式方案近似0；30XXX/31XXX/32XXX保留雪/雨雪/雾露霜来源标志，量按XXX×0.1mm。风速+1000仪器上限标志按缺测处理。保留官方北京时20时日界标签，不默认为UTC日界。缺测可停止，或显式保留-99供WGN生成，不冒充实测。

日照推辐射使用FAO56默认a=0.25、b=0.50，输出标估算并核查天文昼长。更换站点或产品后须重新判断系数适用性。

## WGN统计与缺项

可由完整日历年计算月温度均值/样本标准差、辐射/湿度/风速均值、月降水/雨日数及日降水标准差/偏度。湿日阈值显式记录，当前日所属月份用于转移概率；首日无前日不参与。dew_ave采用当前62.0.1支持的湿度小数解释。

无样本转移、全干月等保持缺项。日总量不能恢复半小时最大雨量pcp_hhr及rain_yrs；从日资料自行构建完整WGN时需另有可靠来源，不能抄其他流域。可选官方完整WGN路线。

## 执行与质量边界

“原始资料转换”先识别/预览，另存来源方案，再转换检查；结果写到案例data/processed的新目录。blockers/missing必须处理，完整后带回建模入口。DEM矩形外缺类别先提示，实际流域内缺覆盖会在Editor前拦截。unknown_policy=nodata不等于填好了分类。处理域须包含上游汇流区，不能默认沿旧流域边界裁剪。

```powershell
& '<QGIS目录>\bin\python-qgis-ltr.bat' -X utf8 '<安装目录>\Workbench\scripts\raw_input.py' --recipe '<案例目录>\自己的案例\config\sources.json' --preview
```

去掉--preview会实际转换，输出另建；退出码2可能表示仍有缺项，查看conversion_report.json。外部案例临时QGIS配置使用独立英文路径；不改日常default。

任意Excel/NetCDF、ISD小时聚日、全自动下载实测资料、特殊城市/山地过程均未通用接入。默认全球GLCC旧地表仅作缺资料时的明确备选，不能冒充当年土地利用。
