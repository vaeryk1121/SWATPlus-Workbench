# 0.0.1-beta.1

首个公开测试版，面向 Windows 10/11 x64 和 QGIS 3.44 / QSWAT+ 4.0.4 / Editor 4.0.2 / SWAT+ 62.0.1。

## 本版功能

- 以安装目录为基准的 EXE 启动器，随包提供 Python、Tkinter 和计算依赖。
- 首次环境自动查找、QGIS 版本检查和手动路径选择，主界面可重新设置环境。
- 自动建模、已有模型运行、参数与敏感性分析、Toolbox 交接和结果回收。
- 水库、作物/受限灌溉和管理情景界面。
- 一个完整 Robit 原生输入教学模型，用于首次运行。
- 可重复执行的 Windows 便携 ZIP 和安装包构建脚本。

## 本次实际检查

- 新增路径迁移与空参数基础运行回归共 9 项通过。既有引擎选择和运行配置回归另有 13 项通过。
- 83 个主脚本及构建脚本通过 Python 语法检查，随后修改的基础运行脚本通过专项回归及实际模型运行。
- 已实际运行安装 EXE，在独立的中文目录安装，使用随包 Python 自动识别本机 QGIS、QSWAT+、Editor、SWATPlus 支持目录和 MPI。
- 已实际构建工作台窗口并打开资料准备、历史结果页面，随包科学计算依赖加载成功。
- 随附 Robit 原生输入模型完成 1990—1991 年运行，预热 1 年，SWAT+ 返回 0，基础任务完成并生成 Toolbox 交接材料。
- 在中文安装目录，以原始 Robit 教学空间和气象资料另建项目，输入检查、QSWAT+ 空间构建、空间检查、Editor 导出和 SWAT+ 运行五个阶段全部返回 0。
- 修复基础运行在空参数列表和 native_calibration 后端组合下的未初始化模块引用错误，补充针对性回归。

## 已知范围

本次独立目录安装和实跑均在开发电脑完成。其他物理电脑上的运行仍需由使用者反馈确认。外部环境识别依赖使用者已安装的兼容组件。首次自动识别遇到特殊安装位置时可手动选择。

原项目历史全量测试曾存在 Tk 销毁、边界提示断言和旧 CSV 夹具缺失问题。本次按实际执行项目报告检查结果。历史全部测试通过的结论尚未建立。

原版 SUFI-2 与 Toolbox 相关功能需要相应外部程序。实际研究的观测率定、精度评价和治理效果需由案例研究分别验证。
